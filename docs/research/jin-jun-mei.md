# Цзинь Цзюнь Мэй

Дата: 2026-08-13

## Расхождение

- Байду-байкэ: 3 г, 80–90 °C, промывка, 15 / 25 / 35…
- Производитель из Тунму (满盏): 5 г / 110 мл, 100 °C, без промывки, проливы по 1 с.

Усреднять нельзя.

## Решение

Осторожный почечный профиль: 3.5 г / 110 мл, 90 °C, необязательная короткая промывка, нарастающие секунды. В карточке чая прямо написано, что другой производитель может требовать кипяток.
