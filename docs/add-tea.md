# Как добавить чай

Через полгода это всё ещё должно хватать.

1. Исследуйте китайские источники. Не выдумывайте секунды.
2. Добавьте источник в `src/data/sources.yaml`.
3. Положите рецепт в `src/data/recipes/<id>.yaml`.
4. Создайте `src/content/teas/<slug>.md`.
5. Если нужна новая подкатегория — `src/content/subgroups/`.
6. При необходимости допишите `docs/research/<slug>.md`.
7. Картинку кладите только с понятной лицензией.
8. Запустите проверки:

```bash
npm run validate
npm test
npm run build
```

9. Откройте страницу чая и пройдите таймер: промывка → первый пролив → обновление страницы.

Идентификаторы только латиницей: `da-hong-pao`, не `да-хун-пао`.

Рецепты не дублируйте на языки. Тексты страницы — в markdown, UI-строки — в `src/i18n/ru.ts`.
